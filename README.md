# Calculadora em C

Projeto desenvolvido em linguagem C para praticar fundamentos de programação.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão

## Conceitos utilizados

- Variáveis
- Funções
- Condicionais
- Entrada e saída de dados

## Como executar

Compile o arquivo main.c e execute o programa.
